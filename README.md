# musl-wasp

Experimental musl libc port for the WASP / wasm-system-platform target.

This repository contains a prototype architecture port of [musl libc](https://musl.libc.org/) for WASP.

## Status

This port is experimental.

Current status:

- based on musl 1.2.5
- adds an initial WASP / WebAssembly architecture prototype
- intended for experimentation and early bring-up
- not production-ready

## Repository history

This repository is based on a snapshot of musl 1.2.5.
